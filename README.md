# Personal Mini-Toolkit

## Project Description

My Personal Mini-Toolkit is a Python program that provides three useful tools in one menu: a simple calculator, a to-do list, and an even or odd checker. The program uses functions, loops, lists, conditional statements, and error handling.

## Tools Included

1. Simple Calculator: Performs addition, subtraction, multiplication, and division.
2. To-Do List: Allows users to add tasks and view their task list.
3. Even or Odd Checker: Checks whether a whole number is even or odd.

## How to Run the Program

1. Install Python.
2. Open PowerShell in the project folder.
3. Run `python toolkit.py`.
4. Follow the menu instructions.
5. Choose option 4 to quit.
