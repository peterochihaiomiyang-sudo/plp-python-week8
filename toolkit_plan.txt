PERSONAL MINI-TOOLKIT - PROJECT PLAN

Project goal:
Create a Python program that provides three useful tools through a menu.

Tool 1: Simple Calculator
- Ask the user for two numbers.
- Allow addition, subtraction, multiplication, and division.
- Handle invalid numbers and division by zero.

Tool 2: To-Do List
- Allow the user to add tasks.
- Display the tasks in a numbered list.
- Use a Python list to store tasks while the program runs.

Tool 3: Even or Odd Checker
- Ask the user for a whole number.
- Use the modulo operator (%) to determine whether it is even or odd.
- Handle invalid input.

Main menu:
- Option 1 opens the calculator.
- Option 2 opens the to-do list.
- Option 3 opens the even or odd checker.
- Option 4 quits the program.

Python concepts:
Functions, lists, loops, conditional statements, user input, and error handling.

Testing plan:
Test each tool with valid input and test how the program handles invalid input.
